5. Method

VSA: ½ × |Σ(F2ᵢ×F1ᵢ₊₁ − F1ᵢ×F2ᵢ₊₁)|, using only the four corner vowels /iː/ → /æ/ → /ɑː/ → /uː/. Area is reported in Hz². This tool is an analysis aid and should be checked against the approved research protocol before thesis/publication use.
