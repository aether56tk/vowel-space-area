# Quadrilateral Vowel Space Analyzer

Browser-based acoustic speech analysis tool for calculating and visualizing Quadrilateral Vowel Space Area (VSA) from F1/F2 formant frequencies.

## Current features
- Four-vowel F1/F2 entry
- Shoelace-formula area calculation
- Substituted equation display
- F1–F2 polygon visualization
- Perimeter
- Centroid
- Example data and reset
- No backend; runs as a static web app

## Research note
Enter the four vowels in a consistent perimeter order. This tool is intended for educational/research use and should not be treated as validated diagnostic software.
